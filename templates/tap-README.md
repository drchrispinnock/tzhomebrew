# Octez Homebrew tap

Prebuilt [Octez](https://octez.tezos.com/) binaries for macOS on Apple
Silicon (arm64) and Intel (x86_64), with launchd services via `brew services`.

These formulae are generated by
[tzhomebrew](https://github.com/drchrispinnock/tzhomebrew). Don't edit them
here.

## Install

```
brew tap drchrispinnock/octez
brew trust drchrispinnock/octez
brew install octez-node octez-client octez-baker
```

Homebrew 7 needs `brew trust` before it will install dependencies, such as
`zcash-params`, from a third-party tap.

Homebrew no longer builds bottles for Intel Macs, so on Intel it compiles the
libraries Octez links against (gmp, zstd, openssl@3, libev, hidapi) from
source, along with their build tools such as cmake. Expect the first install,
and any install after one of those libraries changes, to take a while. Only
the Octez binaries come prebuilt.

## Formulae

| Formula             | Contents                                        |
|---------------------|-------------------------------------------------|
| `octez-client`      | octez-client, octez-admin-client, octez-codec   |
| `octez-node`        | octez-node (service)                            |
| `octez-baker`       | octez-baker, octez-accuser (baker service)      |
| `octez-accuser`     | accuser service                                 |
| `octez-vdf`         | VDF service                                     |
| `octez-dal-node`    | octez-dal-node (service)                        |
| `zcash-params`      | Sapling parameters                              |
| `dal-trusted-setup` | DAL trusted setup                               |

## Services

Each service reads `$(brew --prefix)/etc/octez/<formula>.conf` and logs to
`$(brew --prefix)/var/log/octez/<formula>.log`. Data directories default to
`~/.tezos-node`, `~/.tezos-client` and `~/.tezos-dal-node`.

```
brew services start octez-node
```

`brew services start` runs the service as the logged-in user. To run at boot as
a dedicated user, use
`sudo brew services start --sudo-service-user tezos octez-node`.

The baker needs `LQ_VOTE` set in `octez-baker.conf`. A Mac that sleeps will
miss baking slots.
